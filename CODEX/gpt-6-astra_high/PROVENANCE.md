Agent CODEX; session model `gpt-6-astra`, effort `high`, from runtime
`turn_context` and agreeing CLI configuration on 2026-09-27. A backend build or
snapshot identifier was unavailable. `environment.json` records only relevant

commit hash). Selection was frozen in commit 1812e3f before test evaluation.

external `SKIPPER_DATA_DIR/*.fits`, with SHA-256/size/metadata in data/manifest.json.

## Report and environment

`src/report.py:main` builds report.html from quantitative JSON/CSV and authored
explanatory prose. Every printed primary result is formatted from summary.json,
not retyped. PDF generation uses Matplotlib PdfPages, includes the same figures
and a compact presentation overview; full definitions remain in HTML/METHOD.md.
The PDF and representative figures are rendered/viewed during QA. Unit tests are
`python -m unittest discover -s tests -v` from this run directory.

`reproduce.sh` is the noninteractive entry point. Core dependencies are pinned in
requirements.txt; no network call or model API is needed for scientific analysis.
`data/fetch_data.py` optionally calls gdown5.2.0 with an owner-supplied URL/ID.
The missing URL is explicit, not fabricated. It does not silently extract archives.

## Sources and adaptation versus original work

**New project code:** all Python files in src/, tests/, and data/fetch_data.py;
feature design, split, threshold selection, exposure arithmetic, metrics,
bootstrap orchestration, controls, plotting, report and reproducibility scripts.

**External library algorithms:** Astropy FITS reader; SciPy nonlinear least
squares, connected-component labeling, uniform filter, Spearman correlation;
sklearn IsolationForest; NumPy arrays/histograms/RNG; Matplotlib rendering/PDF.
The Forest algorithm is Liu, Ting & Zhou (2008), doi:10.1109/ICDM.2008.17, not
invented here. The domain-specific sideband descriptor and validation experiment
are this project's implementation. Original reference:
https://cs.nju.edu.cn/zhouzh/zhouzh.files/publication/icdm08b.pdf

**Read-only MOSKITA context:** parent docs/notes/reading_skipper_fits.md,
src/moskita/calibration.py, exposure.py, config.py and AGENTS.md. They informed
active geometry, ADU/electron convention, overscan median and readout exposure.
Those conventions are restated in METHOD.md so reproduction needs no parent code.
No existing anomaly/mask implementation was imported, copied or optimized here.

**Literature considered:** Candès et al. https://arxiv.org/abs/0912.3599;
van Dokkum https://arxiv.org/abs/astro-ph/0108003; SENSEI single-electron model
https://arxiv.org/abs/2106.08347. Used respectively to assess low-rank methods,
reject an individual-sharp-event focus, and qualify exposure/readout assumptions.
No numerical constants for these modules were borrowed from those papers.

**Course:** https://github.com/matiaszaldarriaga/GW-AI-course at
75ba1e0b01df221c7325226d030b22e3a0855e30; final-project.html, day4/session-ai4.html,
day5/session-ai5.html, how-a-page-is-built/page.py. Influenced the separation of
claims, computation, source records and verification, and the portable HTML/PDF.
Scientific examples were not copied. No multi-agent job was invoked.

## What verification does not establish

No independent human review or alternate-model verifier was available in this
run. Separate code paths reduce specific implementation risks, not shared
conceptual errors. Exact timing/mass, physical origin of backgrounds, true-signal
efficiency, robustness to all reconstruction choices, new-module generalization
and production-pipeline superiority remain unverified. The clean-entry repeat
uses the same installed environment, not a separately provisioned machine.
